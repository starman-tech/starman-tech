**🎭 &nbsp;AnimatAI** — *audio vers blendshapes faciaux*
Anime un visage 3D directement depuis une piste vocale. J'ai construit le dataset, entraîné le réseau et développé l'interface autour. Le vrai problème n'était pas le modèle, mais de faire tomber les phonèmes sur la bonne image à 30 FPS.
`PyTorch` `Vision` `Python` — **[voir le repo](https://github.com/starman-tech/AnimatAI)**

**☀️ &nbsp;Planeur solaire** — *vol longue endurance* — **en cours**
Cellule, électronique et logiciel de vol conçus de zéro. La partie intéressante n'est pas le vol, c'est le bilan énergétique : récolter plus qu'on ne consomme, ou se poser.
`STM32` `Fusion 360` `Aérodynamique`

**📱 &nbsp;FocusPCSI** — *minuteur de concentration qui te surveille*
Tourne entièrement dans le navigateur : pas de serveur, pas de compte, aucune donnée qui sort de ta machine. Détecte quand tu prends ton téléphone. Interface néo-brutaliste, volontairement.
`JavaScript` `Local-first` `HTML/CSS` — **[voir le repo](https://github.com/starman-tech/FocusPCSI)**

**🤖 &nbsp;Orion V1** — *bot Discord qui alimente mon site*
Récupère tout depuis GitHub, aucun backend à maintenir.
`Python` `GitHub Actions` — **[voir le repo](https://github.com/starman-tech/Orion-V1-2024)**
